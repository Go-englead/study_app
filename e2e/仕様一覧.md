# study_app E2E 仕様一覧（React フロント向け・清書済み）

`specs/` 配下の Gauge スペック。**React フロント（:8080）＋実API＋実DB** に対して実行する、清書済みのものだけを置いている。
（旧 localStorage 時代の spec は削除済み。未実装機能の spec は機能実装時に追加する）

## 会員（職員操作）
- **会員のキーワード検索** (25) … 全件／氏名／ニックネーム／会員ID／職業／受講開始月で検索
- **会員情報の登録・編集・削除** (26) … 登録→一覧表示→行クリックで編集→反映→削除

## 教材（職員操作）
- **教材を会員に割り当て・解除** (39) … 会員選択→割り当て（1日目標分数）→一覧表示→解除
- **教材の登録・閲覧・編集・削除** (40) … CRUD 通し＋教材名/カテゴリ検索

## 実行
```bash
cd e2e
BASE_URL=http://localhost:8080 API_URL=http://localhost:3000 HEADLESS=true gauge run specs/
```
要素は data-testid で特定、`@BeforeScenario` で API 経由 clean&seed、ログインは dev トークンのため no-op。
