# study_app — 英語コーチング学習管理システム（デモ版）

英語コーチングサービスの**学習管理プラットフォーム**（プロトタイプ）です。

- **公開URL**：https://go-englead.github.io/study_app/
- **ログイン画面**：https://go-englead.github.io/study_app/login.html

---

## 🚀 クイックスタート（デモ環境）

ログイン画面下部の **「🚀 デモアカウントですぐ試す」** から、クリック1つでログインできます。

### 👨‍🏫 コーチでログイン
管理者ダッシュボードを操作できます（会員管理、コーチング記録、教材管理など）。

| 項目 | 値 |
|---|---|
| メール | `demo-coach@example.com` |
| パスワード | `demo123` |

### 👤 会員でログイン
会員ダッシュボードを操作できます（学習記録、教材確認、達成率など）。

| 項目 | 値 |
|---|---|
| メール | `demo-member@example.com` |
| パスワード | `demo123` |

→ ボタンクリックで自動ログインされます。手動で入力する必要はありません。

---

## 🎯 主な機能

### 管理者（コーチ）側（admin.html）
- 👥 **会員管理**：登録／編集／検索／CSV取込・エクスポート
- 📝 **会員カルテ**：プロフィール、学習進捗、PROGOS、コーチング記録
- 🎓 **マンスリーコーチング機能**：教材選定／オリエン／初回／通常コーチング記録
  - テスト内容、卒業/継続ステータス管理
  - 新教材追加、卒業教材一覧
- 📊 **PROGOSスコア管理**：個別登録、CSV一括取込、分析画面
- 📅 **継続プラン管理**：3種類の継続プラン、休会、再入会フロー
- 🔍 **詳細検索**：職業／在住国／渡航先／英語スコア等、9項目で絞り込み

### 会員側（index.html）
- 🔥 **連続学習日数**：ストリーク表示
- 🎯 **本日のデイリーゴール**：円リング進捗
- 📅 **卒業まで・出国までカウントダウン**：管理者側登録データから動的算出
- 📚 **教材の進捗**：教材選定で割り当てられた教材を動的表示
- 🎓 **卒業した教材**：蓄積表示
- 📊 **達成率の推移**：日／週／月ごとの達成率グラフ
- 📅 **学習履歴カレンダー**：月単位で達成状況を可視化
- ⏰ **コーチング予約リマインダー**：前回コーチングから30日経過時にバナー表示

## ⚠️ 注意事項

- これは**デモ環境**であり、**本番運用ではありません**
- 認証情報は GitHub 上で公開されています
- 入力したデータはブラウザの **localStorage** に保存されます（端末をまたぐ同期はされません）
- 個人情報は入力しないでください
- ブラウザのキャッシュをクリアするとデモデータがリセットされます
